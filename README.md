# 👵 JUNTOS+ | Un Espacio para la Amistad y el Bienestar

## 🌟 Misión del Proyecto

**Juntos+** es una *startup* de innovación social con el propósito de **reducir el aislamiento social en adultos mayores (+60 años)**. Desarrollamos una aplicación móvil que prioriza la accesibilidad y seguridad, creando un entorno digital donde los usuarios pueden conectar con personas con afinidades comunes, participar en actividades grupales virtuales y recibir apoyo emocional.

**Nuestro Lema:** *Más que una app, un espacio para la amistad y el bienestar.*

## 🚀 Características Clave (Sprint 1)

El Sprint 1 se centró en la creación de la Landing Page informativa y los mockups de las interfaces de acceso:

1.  **Diseño Centrado en la Accesibilidad:** Interfaz simple, botones grandes, tipografía legible (Inter) y paleta de colores cálidos para una experiencia amigable para el adulto mayor.
2.  **Sección Nosotros:** Comunicación de los valores fundamentales de la marca: Inclusión, Empatía e Innovación Social.
3.  **Formulario de Contacto:** Habilitación del módulo "Say Hello to Us" para consultas de familiares, cuidadores y voluntarios.
4.  **Mockups de Acceso:** Diseño de las interfaces de `Sign In` y `Sign Up` con opciones de inicio de sesión manual y vía redes sociales.

## 🛠️ Tecnologías Utilizadas

* **Frontend (Landing Page):** HTML5, CSS3 (para la estructura y diseño).
* **Diseño/Mockups:** Figma (referencia para la interfaz).
* **Gestión de Proyectos:** Scrum y Kanban (utilizado en el Sprint Backlog).
* **Control de Versiones:** Git & GitHub.
